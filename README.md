## Textbewertung- und optimierung

```markdown
Analysiere diesen Text (INHALT) hinsichtlich: Klarheit (1-10), emotionaler Wirkung (1-10) und Verantwortlichkeit (1-10). Schreibe ihn so um, dass er in allen Kategorien 10/10 erreicht. Zeige mir, was du geändert hast und warum.
````

## Bewerbungsanschreiben

Erzeugt ein Anschreiben, das einen erfahrenen Recruiter überzeugt.

```markdown
Du bist Personalverantwortlicher bei (UNTERNEHMEN) und hast bereits 200 Bewerbungen abgelehnt. Ich bewerbe mich auf die Position (ROLLE). Verfasse ein Anschreiben, das dich innehalten lässt und denken: „Endlich jemand, der es versteht.“
```

## Lebenslauf-Optimierungs

Passt Stichpunkte eines Lebenslaufs an eine konkrete Stellenausschreibung an.

```markdown
Hier ist die Stellenanzeige: (EINFÜGEN).  
Hier ist meine Erfahrung: (EINFÜGEN).  
Schreibe meine Stichpunkte so um, dass die exakten Schlüsselbegriffe aus der Anzeige enthalten sind und quantifiziere die Ergebnisse mit Zahlen, die mich unwiderstehlich machen.
```

## Branchen-Sprache

Formuliert Texte im Ton und Vokabular führender Persönlichkeiten einer Branche.

```markdown
Schreibe diesen Text mit dem Vokabular und Tonfall von Führungspersönlichkeiten aus der Branche (SPEZIFISCHE BRANCHE).  
Füge 3 subtile Machtformulierungen ein, die mich erfahren wirken lassen, ohne arrogant zu erscheinen.
```
