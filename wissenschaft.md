## Paraphrasen-Check

Prüft, ob eine Paraphrase die ursprüngliche Bedeutung korrekt wiedergibt.

```markdown
Hier ist eine Paraphrase eines Zitats: (EINFÜGEN).  
Überprüfe, ob die ursprüngliche Bedeutung erhalten bleibt und nichts falsch verstanden wurde.  
Ich verwende dieses Zitat zur Argumentationsstützung. Prüfe, ob es logisch zu meinem Text passt.
````

## Akademischer Stil

Überprüft wissenschaftliche Neutralität und Objektivität eines Textes.

```markdown
Hier ist ein Absatz aus meiner Arbeit: (EINFÜGEN).  
Prüfe, ob er wissenschaftlich neutral formuliert ist oder zu umgangssprachlich und unausgewogen wirkt.
```

## Fokus auf Hauptergebnisse

Identifiziert das zentrale Ergebnis in Bezug auf die Forschungsfrage.

```markdown
Hier sind drei Ergebnisse aus meiner Untersuchung: (EINFÜGEN).  
Welches Ergebnis stützt oder widerlegt meine Forschungsfrage am stärksten?
```

## Zusammenhangsorientiertes Schreiben

Überprüft Struktur und Klarheit eines Ergebnis-Abschnitts.

```markdown
Hier ist mein Absatz zu den Ergebnissen: (EINFÜGEN).  
Prüfe, ob er klar aufgebaut ist oder wie eine ungeordnete Faktensammlung wirkt.
```

## Abdecken aller Erkenntnisse

Identifiziert fehlende Erklärungen oder Interpretationen.

```markdown
Hier ist meine Zusammenfassung der Ergebnisse: (EINFÜGEN).  
Sag mir, ob wichtige Erkenntnisse noch erklärt oder interpretiert werden müssen.
```

## Analytische Tiefe

Bewertet, ob Analyse statt bloßer Beschreibung erfolgt.

```markdown
Ich habe meine Erkenntnisse mit Theorie X verglichen: (EINFÜGEN).  
Sind meine Überlegungen ausreichend analytisch oder zu beschreibend?
```

## Zusammenhänge darstellen

Überprüft Literaturabgleich auf Klarheit der Übereinstimmungen und Widersprüche.

```markdown
Ich habe meine Ergebnisse mit der bestehenden Literatur verglichen: (EINFÜGEN).  
Habe ich Übereinstimmungen oder Widersprüche klar herausgestellt?
```

## Passende Schlussfolgerung

Überprüft, ob die Schlussfolgerung die Forschungsfrage beantwortet.

```markdown
Hier ist meine Schlussfolgerung: (EINFÜGEN).  
Prüfe, ob ich meine Forschungsfrage klar und vollständig beantworte.
```

## Vollständigkeit Abstract

Checkt, ob alle zentralen Elemente enthalten sind.

```markdown
Hier ist mein Abstract: (EINFÜGEN).  
Prüfe, ob Forschungsfrage, Methode, Ergebnisse und Schlussfolgerungen vollständig und klar dargestellt sind.
```
